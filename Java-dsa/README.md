# Java-dsa — Beginner to Advanced

A step-by-step Java learning path based on [JAVA.md](../JAVA.md).
Each topic has its own folder of runnable `.java` files with explanations in the comments.

## How to run any file

Java 11+ can run a single source file directly. You don't need `javac` first (Spring-Boot is the exception: it's a Maven project, see its README):

```bash
cd Java-dsa/Core-Java/01-Fundamentals
java DataTypesAndVariables.java
```

Read a file top to bottom: the big comment block at the top explains the theory, and each method shows one concept with its output.
