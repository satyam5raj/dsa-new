# dsa-new
Dsa and design using typescript

## Learning Plan

Data Structures & Algorithms in TypeScript, built up topic by topic. Data structures first, then algorithms/problem solving, then system design later.

### Data Structures (implementation order)

1. Arrays — static + dynamic array
2. Linked Lists — singly, doubly, circular
3. Stack
4. Queue — simple, circular, deque, priority queue (via heap)
5. Hash Table — custom implementation w/ collision handling
6. Trees — Binary Tree → Binary Search Tree → Balanced (AVL) → Segment Tree / Fenwick Tree (BIT)
7. Heap — Min-Heap, Max-Heap
8. Graph — adjacency list, adjacency matrix
9. Trie — prefix tree
10. Union-Find / Disjoint Set
11. Advanced (optional) — LRU Cache (hashmap + doubly linked list), Skip List, Bloom Filter

### Later

- Algorithms & problem solving
- System design
